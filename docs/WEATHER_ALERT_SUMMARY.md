# Weather Alert Feature - Executive Summary

## 功能概述

**需求：** 當伴侶所在地出現惡劣天氣（暴雨、暴雪、極端天氣警報）時，即使沒有開啟 APP 也能收到即時推播通知。

**使用場景：** 你在美國，女友在台灣 → 台北出現豪雨警報 → 你立即收到通知：「⚠️ 豪雨警報：台北 - 每小時降雨量 35mm，提醒她帶傘！」

## 📋 功能清單

### 核心功能

1. **即時天氣警報** ⚠️
   - 政府發布的嚴重天氣警報（颱風、洪水、龍捲風）
   - 強降雨/暴雪（>20mm/小時 或 >5cm/小時）
   - 極端溫度（>38°C 或 <-10°C）
   - 雷暴和閃電活動
   - 劇烈天氣變化（3 小時內溫度驟降 >15°C）

2. **智慧通知控制** 🔔
   - 嚴重程度篩選（僅緊急 / 高優先級以上 / 全部）
   - 勿擾時段（例：晚上 11 點 - 早上 7 點僅通知緊急警報）
   - 防洪機制（同一事件 3 小時內僅通知一次）
   - 測試通知按鈕

3. **通知內容** 📱
   - 警報類型和嚴重程度
   - 伴侶城市名稱（例：「台北」或「紐約」）
   - 簡短描述（例：「豪雨 - 每小時 35mm」）
   - 時間戳
   - 建議行動（例：「提醒她帶傘」）

### 通知範例

**緊急警報：**
```
🚨 Aura: Long Distance Couples
⚠️ 嚴重天氣：台北
颱風警報 - 請待在室內。你的伴侶應避免外出。
```

**高優先級警報：**
```
🌦️ Aura: Long Distance Couples
⚠️ 豪雨警報：紐約
預計每小時降雨 35mm。提醒你的伴侶帶傘！🌂
```

**中優先級警報：**
```
☃️ Aura: Long Distance Couples
❄️ 冬季天氣：芝加哥
大雪（每小時 8cm）。道路可能濕滑。問候你的伴侶！
```

## ⚠️ 隱私與安全

### 資料收集
- **位置資料**：僅儲存伴侶城市座標（非 GPS 精確位置）
- **推播 Token**：Expo 推播通知 token
- **警報偏好**：嚴重程度門檻、勿擾時段

### 隱私措施
- ✅ 傳輸加密（HTTPS）
- ✅ 不與第三方分享位置資料
- ✅ 用戶可隨時刪除所有資料
- ✅ 符合 GDPR/CCPA 規範

### 安全措施
- ✅ API 端點速率限制（防濫用）
- ✅ 所有位置資料輸入驗證
- ✅ Expo push token 驗證
- ✅ 安全憑證儲存（環境變數）

## ❓ 常見問題

### Q: 會耗電嗎？
**A:** 不會。所有天氣檢查都在伺服器端進行，你的手機只在檢測到惡劣天氣時接收通知。耗電量類似於接收簡訊。

### Q: 晚上不想收到通知怎麼辦？
**A:** APP 有「勿擾時段」設定。你可以設定不接收非緊急警報的時間（例：晚上 11 點 - 早上 7 點）。緊急警報（颱風、龍捲風）仍會通知。

### Q: 天氣警報準確嗎？
**A:** 美國和台灣使用官方政府氣象 API（美國國家氣象局和台灣中央氣象署）。這些是專業天氣 APP 使用的相同來源。

### Q: 伴侶會知道我在追蹤她的天氣嗎？
**A:** 是的，這是設計為雙方共同功能。啟用前建議兩人一起討論此功能。

### Q: 隱私如何？會儲存我的位置嗎？
**A:** 我們僅儲存伴侶的城市級別位置（非 GPS 座標）。資料已加密且僅用於檢查天氣。你可以隨時在設定中刪除所有資料。

### Q: 支援全球嗎？
**A:** 是的！我們針對美國和台灣有專屬 API（官方政府來源），其他國家使用全球備援 API。
