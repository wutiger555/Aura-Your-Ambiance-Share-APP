# Intro Screen Redesign: A Visual Journey

## 🎬 設計理念：從分離到連結的詩意旅程

### 核心故事
**"兩個人，不同的天空，一個共享的氛圍"**

這不只是一個 Landing Page，而是一個 **8秒的視覺敘事**，讓使用者在進入 App 前就能感受到 Aura 的核心價值：將遠距離戀人的兩個孤獨世界，透過科技編織成一個共享的情感空間。

---

## 🎭 四幕劇結構

### 第一幕：分離 (0-2秒)
**視覺：** 兩個小地球從螢幕左右兩側淡入並移動到位

- **左側地球**：青色光暈（代表你）
- **右側地球**：粉紅光暈（代表伴侶）
- **象徵意義**：兩人各自在自己的世界，距離遙遠

**情感基調：** 孤獨、分離、渴望

### 第二幕：橋樑 (2-4秒)
**視覺：** Aura Logo 在中央出現並發光

- Logo 從 0.5 倍大小彈跳放大到正常
- 外圍出現脈動光環
- Logo 持續呼吸般的發光

**象徵意義：** Aura 作為連接兩人的橋樑和媒介

**情感基調：** 希望、可能性

**文字：**
- "Two people."（兩個人）

### 第三幕：連接 (4-6秒)
**視覺：** 能量線從兩側地球流向中央 Logo

- 兩條曲線優雅地生長，像藤蔓或能量流
- 左側青色線，右側粉紅線
- 使用 strokeDasharray 動畫創造「描繪」效果
- 粒子系統開始出現

**象徵意義：** 情感和思念的流動，主動的連結嘗試

**情感基調：** 行動、流動、連結中

**文字：**
- "Different skies."（不同的天空）

### 第四幕：統一 (6-8秒)
**視覺：** Heartline 預覽出現在中央下方

- 標誌性的彎曲線條淡入
- 粒子系統達到全透明度
- 整個畫面和諧統一

**象徵意義：** 最終的連接完成，兩個世界融為一體

**情感基調：** 和諧、圓滿、期待

**文字：**
- "One shared atmosphere."（一個共享的氛圍）- **金色高亮**
- "Feel your partner's weather and time, blended with yours in real-time."

## 🎨 視覺元素詳解

### 1. 兩個小地球 (Mini Globes)

**設計：**
- 直徑 60px 的 SVG 圖形
- 三層結構：
  1. 外層光暈 (Radial Gradient, 半透明)
  2. 中層圓圈 (半透明填充 + 發光描邊)
  3. 核心光點 (實心，代表位置)

**顏色語言：**
- **左側（你）**：`rgba(6, 182, 212)` - Cyan/青色
  - 象徵：清新、開放、第一視角
- **右側（伴侶）**：`rgba(236, 72, 153)` - Pink/粉紅
  - 象徵：溫暖、思念、對方

**動畫：**
- 從螢幕外側滑入 (`translateX: -100 → 0` / `100 → 0`)
- 1.5 秒緩動曲線 (`Easing.out(Easing.cubic)`)
- 錯開 200ms 讓動畫更有層次

### 2. Aura Logo

**使用現有的 AuraLogo 組件**，但不使用內建動畫

**增強：**
- **光環效果**：140px 的圓形光暈在後方
- **呼吸動畫**：光環的透明度 0.3 → 1 持續脈動
- **彈跳進場**：使用 `Easing.back(1.2)` 創造彈性感

**象徵意義：**
- Logo 的漸變色（黃→粉→藍）已經隱含了融合的概念
- 中央白點代表連接的核心

### 3. 能量連接線 (Energy Connection Lines)

**技術實現：**
- 兩條貝塞爾曲線 (Quadratic Bezier)
- 使用 `strokeDasharray` 和 `strokeDashoffset` 動畫
- 創造「從無到有繪製」的效果

**路徑設計：**
```
左線：從左地球 → 向上彎曲 → 中央Logo
右線：從右地球 → 向上彎曲 → 中央Logo
```

**視覺細節：**
- 線寬：2px
- 顏色：與對應地球相同
- 透明度：60%
- 動畫時長：1.5 秒

**象徵意義：**
- 不是直線，而是曲線 = 情感的路徑不是直接的，而是有波折的
- 雙向流動 = 平等的關係，不是單向的依賴

### 4. Heartline 預覽

**設計：**
- 主畫面 Heartline 的簡化版本
- 只有一條簡單的彎曲線
- 位於畫面中央偏下

**象徵意義：**
- 預告使用者將看到的核心功能
- 視覺上的「承上啟下」，從故事過渡到實際功能

## ✍️ 文案設計

### 敘事結構

1. **"Two people."** (第2秒出現)
   - 簡單、直白
   - 建立故事的主角

2. **"Different skies."** (第4.5秒出現)
   - 強調差異和距離
   - 製造張力

3. **"One shared atmosphere."** (第6.5秒出現)
   - **金色高亮** (`#fbbf24`)
   - 核心價值主張
   - 解決張力，給出希望

4. **描述文字** (第7.5秒出現)
   - "Feel your partner's weather and time, blended with yours in real-time."
   - 解釋具體功能
   - 從情感過渡到實用

### 文案特色

- **詩意節奏**：短句、對仗、漸進
- **從抽象到具體**：從「天空」到「天氣和時間」
- **情感共鳴**：不談功能，先談感受

- 從分離（黑夜）→ 希望（黎明）→ 連接（白天）

- Logo 的呼吸光暈
- 能量線的流動
- 都是「呼吸」和「流動」的視覺化

## 🚀 如何測試

### 切換到新版 Intro

在 [`App.tsx`](../apps/mobile/App.tsx) 中：

```typescript
// 將這行
import IntroScreen from './src/components/aura/IntroScreen';

// 改為
import IntroScreen from './src/components/aura/IntroScreenRedesign';
```

### 測試重點

1. **時間把控**：是否 8-9 秒內完成整個敘事？
2. **情感節奏**：是否有起承轉合的感覺？
3. **視覺清晰度**：地球、Logo、連接線是否清楚可見？
4. **文字可讀性**：在實際設備上文字是否容易閱讀？
5. **整體和諧**：顏色、動畫、文字是否和諧統一？

### 可調參數

如果想調整時序，主要參數在 `useEffect` 中：

```typescript
// 地球出現時間
leftGlobeOpacity.value = withTiming(1, { duration: 1000 });

// Logo 延遲時間
logoOpacity.value = withDelay(2000, ...);

// 連接線延遲時間
connectionProgress.value = withDelay(4000, ...);

// Heartline 延遲時間
heartlineOpacity.value = withDelay(6000, ...);
```

## 📝 設計師筆記

這個設計的靈感來自：
- **電影開場**：緩慢、有節奏地建立世界觀
- **繪本敘事**：逐頁翻開，逐步揭示故事
- **音樂漸強**：從安靜到高潮的情緒曲線

關鍵設計決策：
1. **為什麼用地球而不是人像？**
   - 地球更抽象，更普遍適用
   - 避免性別、種族等具象化的限制
   - 地球本身就有「位置」和「距離」的隱喻

2. **為什麼連接線向上彎曲？**
   - 向上 = 希望、積極、正向
   - 如果向下會有「墜落」的負面感

3. **為什麼用 8 秒而不是更短？**
   - 太短（<5秒）：無法建立情感連結
   - 太長（>10秒）：使用者失去耐心
   - 8秒：剛好講完一個起承轉合的小故事
