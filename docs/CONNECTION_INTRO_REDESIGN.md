# ConnectionIntro Redesign: The Bridge Between Worlds

## 🎬 設計理念：完整敘事的中間章節

ConnectionIntro 不再只是一個 Loading 畫面，而是連接 **Intro Screen** 和 **Main Screen** 的**敘事橋樑**。

### 敘事連貫性

```
Intro Screen              ConnectionIntro            Main Screen
兩個地球出現      →      地球轉化為真實位置    →    完整的天空融合
能量線連接              地圖浮現 + Heartline        活著的 Heartline
抽象概念                具象化過程                  實時體驗
```

---

## 🎭 五幕劇結構（10 秒）

### 第一幕：延續（0-2 秒）
**視覺：** 兩個地球脈動進場，與 Intro Screen 相同

- 左側地球（青色）代表你
- 右側地球（粉紅色）代表伴侶
- 從小到大的彈性動畫
- **設計意圖**：讓使用者感受到故事的連續性

**文字：** （無，讓視覺說話）

---

### 第二幕：呼吸（2-4 秒）
**視覺：** 地球開始"呼吸"脈動

- 外圍光暈隨著呼吸節奏擴張收縮
- 0.9-1.1 倍的輕微縮放
- 透明度 0.5-0.8 波動
- **象徵意義**：兩人都在等待連接，心跳在同步

---

### 第三幕：世界浮現（4-6 秒）
**視覺：** 世界地圖從背景淡入

- 使用 MinimalistWorldMap（極簡線條）
- 半透明白色描邊（30% 透明度）
- 地圖緩慢放大到正常尺寸
- 城市標記點淡入（青色和粉紅色點）

**文字：** "Weaving Your Connection"（編織你們的連接）

**技術細節：**
- 地圖使用實際經緯度轉換算法
- 支援全球任何兩個城市
- 標記位置精確對應真實地理位置

---

### 第四幕：Heartline 形成（6-8 秒）
**視覺：** 連接線從左地球繪製到右地球

- 使用貝塞爾曲線（與主畫面 Heartline 相同路徑）
- 線條從無到有"繪製"出來
- 繪製完成後開始呼吸脈動
- 外圍有柔和光暈

**文字：** "{城市名} ✦ {城市名}"

**動畫細節：**
```typescript
// 繪製動畫
strokeDasharray + strokeDashoffset

// 呼吸動畫
strokeOpacity: 0.5 → 1.0 (2秒週期)
```

**象徵意義：**
- 繪製 = 建立連接的過程
- 呼吸 = 連接是活著的、持續的

---

### 第五幕：融合（8-10 秒）
**視覺：** 所有元素淡出，漸變層淡入

- 地球、地圖、Heartline 一起淡出
- 漸變層從底部往上淡入
- 顏色過渡到主畫面的漸變色
- 無縫過渡到 BlendedSky

**過渡顏色：**
```
深藍灰 (#1e293b) → 深紫 (#312e81) → 深藍 (#1e1b4b)
```

## 🎨 視覺元素詳解

### 1. 兩個地球（延續 Intro Screen）

**結構：**
```
外層：脈動光暈（RadialGradient）
中層：半透明填充 + 發光描邊
核心：實心光點
```

**顏色不變：**
- 左（你）：Cyan `rgba(6, 182, 212)`
- 右（伴侶）：Pink `rgba(236, 72, 153)`

**新增：呼吸動畫**
- 週期：3 秒（1.5s 擴張，1.5s 收縮）
- 縮放範圍：0.9-1.1 倍
- 透明度範圍：0.5-0.8

### 2. 世界地圖

**使用現有 MinimalistWorldMap 組件**

**設定：**
- 寬度：95% 螢幕寬
- 高度：寬度的一半（2:1 比例）
- 描邊：`rgba(255, 255, 255, 0.3)`
- 線寬：1px

**位置：**
- 垂直居中略偏上（25% from top）
- 水平居中

**淡入動畫：**
- 時間：4-6 秒
- 透明度：0 → 0.6
- 縮放：0.7 → 1.0

### 3. 城市標記

**設計：**
- 內圓：實心，直徑 8px
- 外圓：描邊，直徑 16px，透明度 40%
- 顏色：與對應地球相同

**位置計算：**
```typescript
// 經緯度 → 地圖座標（Mercator 投影簡化版）
x = ((lon + 180) / 360) * 360
y = ((90 - lat) / 180) * 180
```

**淡入動畫：**
- 時間：5-6.5 秒
- 透明度：0 → 1

### 4. Heartline 連接線

**路徑：**
```
起點：左地球中心
控制點：螢幕右側 65%，垂直中央
終點：右地球中心

公式：Quadratic Bezier Curve
M startX,startY Q controlX,controlY endX,endY
```

**視覺層次：**
1. 主線：白色，2px，呼吸脈動
2. 光暈：淺藍色，8px，50% 透明度

**動畫：**
- **繪製**（6-8秒）：strokeDashoffset 動畫
- **呼吸**（8秒後開始）：透明度 0.5 ↔ 1.0，2秒週期

## 💡 設計決策解釋

### 1. 為什麼 10 秒而不是 8 秒？

原版是 8 秒，但新版需要：
- 更多時間建立地球呼吸
- Heartline 繪製 + 呼吸需要 4 秒
- 平滑的五幕結構

**用戶不會覺得太長，因為：**
- 持續有新元素出現
- 動畫流暢不卡頓
- 有情感節奏（起承轉合）

### 2. 為什麼保留地球，不直接顯示地圖？

- **連貫性**：Intro Screen 建立了地球的視覺語言
- **過渡**：從抽象到具象的自然演變
- **情感**：地球呼吸創造等待的張力

### 3. 為什麼 Heartline 要呼吸？

- **預告**：讓使用者知道主畫面會看到什麼
- **統一**：所有"連接"元素都會呼吸
- **生命力**：強化"活著的連接"主題

### 4. 為什麼顯示城市名稱？

- **個人化**：讓使用者感受到"這是我的故事"
- **確認**：視覺化確認輸入正確
- **期待**：即將看到這兩個城市的天氣融合

## 🚀 技術亮點

### 1. 精確的經緯度轉換
```typescript
const latLongToMapCoords = (lat: number, lon: number) => {
  // Mercator 投影簡化版
  const x = ((lon + 180) / 360) * 360;
  const y = ((90 - lat) / 180) * 180;
  return { x, y };
};
```

### 2. 貝塞爾曲線 Heartline
```typescript
// 與主畫面相同的曲線公式
const path = `M ${startX} ${startY} Q ${controlX} ${controlY} ${endX} ${endY}`;
```

### 3. 多層動畫同步
- 使用單一 `masterProgress` (0-1)
- 用 `interpolate` 切分時間段
- 確保所有動畫完美同步

### 4. React Native Reanimated v4
- 所有動畫運行在 UI 線程
- 60fps 流暢體驗
- 不阻塞 JavaScript 主線程
