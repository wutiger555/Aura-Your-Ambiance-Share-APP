# Aura v2.6.0 - Minimalist Redesign

## 🎯 Overview

Version 2.6.0 represents a complete UI/UX overhaul focused on returning Aura to its core minimalist philosophy. This redesign addresses user feedback about information overload while maintaining emotional resonance and providing user customization.

---

## ✨ Key Improvements

### 1. **Minimal Mode (Default)**

The app now defaults to a **ultra-clean interface** showing only essential information:

**Main Screen:**
- City name (simple, clean)
- Time (large, prominent clock)
- Temperature + Weather icon
- Living Heartline with breathing animation

**Hidden by default:**
- Relationship milestones
- Weather reminder cards
- Profile names & emojis
- Sunrise/Sunset times
- Time status icons
- Distance/time difference info

---

### 2. **User-Controlled Display Settings**

New **Display Settings** panel allows users to customize their experience:

**Three Appearance Modes:**
- **Minimal** (Default): Core information only, maximum tranquility
- **Balanced**: Core + selected personalization (profiles, milestones, distance)
- **Detailed**: All features from v2.5.0

**Granular Element Toggles:**
Users can individually show/hide:
- [ ] Relationship milestones
- [ ] Weather reminders
- [ ] Profile names & emojis
- [ ] Sunrise/sunset times
- [ ] Time status icons
- [ ] Status messages
- [ ] Heartline distance/time info

## 🏗️ Architecture Changes

### New Store: `useDisplaySettings`

```typescript
interface DisplaySettings {
  // Element visibility
  showMilestones: boolean;
  showWeatherReminders: boolean;
  showProfileInfo: boolean;
  showSunTimes: boolean;
  showTimeStatus: boolean;
  showStatusMessages: boolean;
  showHeartlineInfo: boolean;

  // Appearance preset
  appearanceMode: 'minimal' | 'balanced' | 'detailed';

  // Position swap
  swappedPositions: boolean;
}
```

**Persisted to AsyncStorage** - Settings survive app restarts

### Core Principles (CLAUDE.md)

1. ✅ **Emotional resonance over functionality**
   - Minimal mode removes UI noise
   - Breathing animations create calm
   - Location swap adds playfulness

2. ✅ **Minimalist aesthetics**
   - Generous whitespace
   - Only core info by default
   - Glass morphism & subtle glows

3. ✅ **"Night to Dawn" narrative**
   - Gradient borders echo day/night
   - Living Heartline symbolizes connection
   - Swap button enables perspective shift

4. ✅ **Micro-interactions over jarring animations**
   - 30s gear rotation (barely noticeable)
   - 4s breathing pulses (meditative)
   - 180° swap rotation (smooth, delightful)

## 🚀 Migration Guide

### For Users

1. **App will auto-update to Minimal mode**
   - Clean, simple interface
   - All features still accessible via Settings

2. **To customize:**
   - Tap ⚙️ gear icon (bottom-right)
   - Go to Display tab
   - Choose appearance mode or toggle elements

3. **To swap positions:**
   - Tap ⇅ button in center of Heartline
   - Positions exchange with smooth animation

### For Developers

**New dependencies:**
- None! Uses existing packages

**Breaking changes:**
- None - backwards compatible
- Old Settings/Heartline components preserved

**Testing:**
```bash
# Clear cache and run
cd apps/mobile
npx expo start -c
```
