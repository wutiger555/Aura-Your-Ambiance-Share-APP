## 🚀 上架流程

1. **创建 App Store Connect 记录**
   - 使用 Bundle ID: `com.aura.ambianceshare`（现有）或更新为 `com.aura.ldrcouples`

2. **上传构建版本**
   - 通过 Xcode Archive 或 EAS Build
   - 确保 AlarmKit 配置正确

3. **填写所有元数据**
   - 按照本文档配置
   - 准备截图和视频

4. **提交审核**
   - 审核时间通常 24-48 小时

5. **上架后**
   - 监控评论和评分
   - 追踪 ASO 指标
   - 持续优化
